# WO Mic Next 0.1.3

## 简体中文

- 新增简体中文与英语界面切换，并保存所选语言。
- 新增麦克风传输开关。静音时继续保持手机连接、接收音频和本地监听，只向 WO Mic 虚拟麦克风写入静音音频。
- 新增专用麦克风图标；托盘图标以红色表示未连接、绿色表示已连接，静音时显示斜线。
- 更新应用状态、提示和错误消息的英文翻译。

需要单独安装并正常工作的 WO Mic Windows 驱动。此版本的 Windows x64 发行包采用自包含发布，不需要另外安装 .NET Desktop Runtime。

## English

- Added Simplified Chinese and English UI, with the selected language saved.
- Added a microphone transmission toggle. Muting keeps the phone connection, audio reception, and local monitoring active while sending silence to the WO Mic virtual microphone.
- Added a custom microphone icon. The tray icon is red when disconnected and green when connected; a slash indicates mute.
- Translated application status, alerts, and error messages.

The WO Mic Windows driver must be installed separately and working. The Windows x64 package for this release is self-contained and does not require a separate .NET Desktop Runtime installation.
